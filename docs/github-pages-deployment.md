# GitHub Pages 公開手順書

本プロジェクト（Alirex Labs. 公式サイト）を GitHub Pages にデプロイし、Web上で一般公開する手順です。
本リポジトリは静的ファイル（HTML/CSS/JS/assets）のみで構成されており、ビルドプロセスなしで即座に公開可能です。

---

## 🚀 公開手順

1. **GitHub リポジトリを開く**
   * 対象リポジトリ（`AlirexLabsOfficialSite`）のトップページから、画面上部の **「Settings」**（設定）タブをクリックします。

2. **Pages 設定画面へ移動**
   * 左側のサイドバーメニューから **「Pages」** をクリックします。

3. **ブランチと公開フォルダの指定**
   * **「Build and deployment」** セクションの **「Source」** で **`Deploy from a branch`** が選択されていることを確認します。
   * **「Branch」** 設定にて、以下を指定します：
     * ブランチ名: **`main`**
     * フォルダ: **`/ (root)`**
   * **「Save」** ボタンをクリックします。

4. **デプロイの完了確認**
   * 数十秒〜1分程度待つと、自動的に GitHub Actions によるデプロイワークフローが実行されます。
   * 画面上部に **「Your site is live at `https://<ユーザー名>.github.io/<リポジトリ名>/`」** と表示されれば公開完了です。

---

## 🔍 公開されるページ構成

* **公式サイトトップ**: `https://<ユーザー名>.github.io/<リポジトリ名>/`
  （※ 組織サイト `alirexlabs.github.io` の場合はルート直下で配信されます）

※ リポジトリルートに配置されている `.nojekyll` ファイルにより、Jekyll の構文処理をバイパスし、すべての静的アセットが正常に配信されます。
